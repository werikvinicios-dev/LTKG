# Armorial de Aresta
Símbolos originais do repositório LTKG, preservados em Originais_GitHub.
Commit de origem: a15dae77c5f564f4b5d137baf9ee07d490ee1868.
Os 175 SVGs das cinco famílias foram conferidos por hash Git. Nenhuma escrita no GitHub.

Os brasões, bandeiras e estandartes desta pasta são NOVAS APLICAÇÕES EDITORIAIS dos símbolos existentes, não novas instituições ou regras. As paletas de aplicação são propostas gráficas. A pasta regioes_conceituais mantém os estudos regionais com os nomes do acervo; eles não estabelecem fronteiras, distâncias ou geografia canônica.

Os SVGs são editáveis. Os PNGs transparentes são exportações dos vetores em 2x, sem ampliação de bitmap. A área de desenho dos símbolos foi ampliada para preservar traços que ultrapassavam o viewport original. O desenho dos emblemas não foi redesenhado.

A iconografia das etapas foi reaproveitada com o sistema atual de selos. O antigo guia do repositório sobre âncoras obrigatoriamente físicas não foi usado como regra atual.
